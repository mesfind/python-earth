Python

Python is a popular language for research computing, and great for general-purpose programming as well. Installing all of its research packages individually can be a bit difficult, so we recommend Anaconda, an all-in-one installer.

Regardless of how you choose to install it, please make sure you install Python version 3.x (e.g., 3.4 is fine).

Windows

Video Tutorial
  1. Open http://continuum.io/downloads with your web browser.
  2. Download the Python 3 installer for Windows.
  3. Install Python 3 using all of the defaults for installation except make sure to check Make Anaconda the default Python.

Mac OS X

Video Tutorial
  1. Open http://continuum.io/downloads with your web browser.
  2. Download the Python 3 installer for OS X.
  3. Install Python 3 using all of the defaults for installation.

Linux

  1. Open http://continuum.io/downloads with your web browser.
  2. Download the Python 3 installer for Linux.
  3. Open a terminal window.
  4. Type 
    bash Anaconda3-
    and press tab to autocomplete the filename.
  5. Press enter and follow the prompts (type yes when asked).
  6. Close the terminal window.

GNU Octave

GNU Octave is a high-level language primarily intended for numerical computations. It provides a convenient command-line interface for solving linear and nonlinear problems numerically.

Windows

  1. Open https://www.gnu.org/software/octave/download
  2. Under "Microsoft Windows", click the installer link for the latest stable version.
  3. Download and run the .exe installer.
  4. Follow the installation wizard, accepting the default options.

Mac OS X

  1. Open https://www.gnu.org/software/octave/download
  2. Under "macOS", click the installer link for the latest stable version.
  3. Download the .dmg file and open it.
  4. Drag the Octave application to your Applications folder.

Linux

  1. Open a terminal window.
  2. For Debian/Ubuntu: 
    sudo apt-get update && sudo apt-get install octave
  3. For Fedora/RHEL: 
    sudo dnf install octave
  4. Launch with octave command.

Note: On Windows and Mac, you may also want to install the Octave Forge packages which provide additional functionality.

MATLAB

MATLAB is a proprietary multi-paradigm numerical computing environment. Many institutions provide licenses for their members.

Windows

  1. Check with your institution about MATLAB license availability
  2. Create a MathWorks account using your institutional email
  3. Download the installer from MathWorks Downloads
  4. Run the installer and follow the instructions
  5. Activate using your institutional license

Mac OS X

  1. Check with your institution about MATLAB license availability
  2. Create a MathWorks account using your institutional email
  3. Download the installer from MathWorks Downloads
  4. Open the .dmg package and run the installer
  5. Activate using your institutional license

Linux

  1. Check with your institution about MATLAB license availability
  2. Create a MathWorks account using your institutional email
  3. Download the installer from MathWorks Downloads
  4. Run the installer from terminal: 
    sudo ./install
  5. Activate using your institutional license

Note: If you don't have institutional access, MathWorks offers a Home license or a student version at reduced cost. For temporary use, you can also try MATLAB Online.
